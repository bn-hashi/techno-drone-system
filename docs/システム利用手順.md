## 1. システム概要

本システムは二等無人航空機操縦士の学科オンライン講習を管理するシステムです。  
受講者が動画学習・確認試験・質疑応答を行い、管理者が受講管理・成立判定・証明書発行を行います。

### ロール

| ロール | 説明 |
|--------|------|
| 受講者 (STUDENT) | 動画受講・試験・Q&A・証明書ダウンロードを行う |
| 管理者 (ADMIN) | 受講者管理・コース管理・成立判定・証明書発行を行う |

### 管理者ナビゲーション

ログイン後の管理者画面には左サイドバーに以下のメニューが表示されます。

| メニュー | 遷移先 |
|----------|--------|
| 受講者管理 | `/admin/users` |
| 入学申請 | `/admin/applications` |
| コース管理 | `/courses` |
| 動画管理 | `/videos` |
| 問題バンク | `/questions` |
| 試験結果 | `/exam-results` |
| 質疑応答 | `/admin/qa` |

## 2. 受講者の利用手順

### 2-1. 初回セットアップ

管理者から招待メールが届いた後、以下の手順でアカウントを設定します。

1. **規約同意ページ** (`/setup/agreement`) にアクセスする
   - メール内のリンクをクリックするとこのページに遷移します
   - 利用規約を読み、「同意する」をクリックします
2. **パスワード設定ページ** (`/setup/password`) でパスワードを設定する
   - 設定完了後、自動的にログインページに遷移します

### 2-2. ログイン

1. `/login` にアクセスする
2. 登録済みのメールアドレスとパスワードを入力する
3. 「ログイン」ボタンをクリックする

> **注意:** アカウントのステータスが `ACTIVE`（受講中）でないと学習画面にアクセスできません。

### 2-3. 動画受講

1. コース一覧からコースを選択する (`/courses/{courseId}`)
2. 動画一覧が表示される
   - ロック中の動画は順番に解放されます（前の動画を視聴すると次が解放されます）
3. 「視聴」ボタンをクリックして動画を再生する
4. **視聴ログは自動で記録されます**（科目別の受講時間に累積されます）

> **不正行為について:** 以下の行為は検知されます。
> - タブ離脱（動画視聴中に別のタブに移動）
> - 同時ログイン（複数端末での同時利用）
> - 再生速度の違反（1.5倍速超）

### 2-4. 修了確認試験

1. 全科目の受講時間を満たしたら試験を受けられます
2. `/exams` にアクセスして受験条件を確認する
   - 不足科目がある場合は一覧で表示されます
3. 「試験を開始する」ボタンをクリックして開始する
4. 問題に回答して「提出する」をクリックする
5. 結果画面で合否とスコアを確認する

> 合格後、ステータスが `EXAM_PASSED`（試験合格）に変わります。  
> 管理者による成立判定を待ってください。

### 2-5. 質疑応答

1. `/qa` にアクセスする
2. 質問内容を入力して送信する
3. 管理者からの回答をこのページで確認できます

### 2-6. 修了証明書のダウンロード

成立判定・証明書発行が完了したら証明書をダウンロードできます。

1. `/certificate` にアクセスする
2. 証明書番号・発行日時・有効期限を確認する
3. 「PDF をダウンロード」ボタンをクリックしてダウンロードする

## 3. 管理者の利用手順

### 3-1. 受講者の新規登録〜招待までの流れ

受講者を登録して招待メールを送るまでの一連の手順です。

#### ステップ 1: アカウント作成

1. サイドバーの「**受講者管理**」をクリックして受講者一覧ページに移動する
2. 右上の「**新規登録**」ボタンをクリックする
3. 以下を入力して「登録」する
   - メールアドレス（必須）
   - 氏名
   - 仮パスワード
   - コースタイプ（初学者 / 経験者）
4. 登録後、ステータスが `PENDING_REGISTRATION` になります

#### ステップ 2: 入学申請情報の登録

1. サイドバーの「**受講者管理**」をクリックして受講者一覧を開く
2. 対象の受講者行にある「**入学申請**」ボタンをクリックする
3. 以下を入力して登録する
   - 生年月日（必須）
   - 住所（必須）
   - 電話番号（必須）

#### ステップ 3: ステータスを PENDING_ACTIVATION に変更

1. 受講者管理ページ（「**受講者管理**」メニュー）で対象の受講者行にある「**ステータス変更**」ボタンをクリックする
2. 確認ダイアログで「OK」をクリックする
3. ステータスが `PENDING_ACTIVATION` に変わります（これで招待メール送信が可能になります）

#### ステップ 4: 招待メールの送信

1. 受講者管理ページで対象の受講者行にある「**詳細**」ボタンをクリックして受講者詳細ページに移動する
2. 黄色い枠の中に「招待メールを送信」ボタンが表示されていることを確認する
   - ステータスが `PENDING_ACTIVATION` の場合のみ表示されます
3. ボタンをクリックして送信する
4. 受講者のメールアドレスに初回セットアップ用リンクが届きます

> **注意:** 環境変数 `APP_BASE_URL` が未設定の場合、招待メール内のリンクが正しく生成されません。

#### ステップ 5: 受講者がセットアップを完了する

受講者が招待メールのリンクから規約同意・パスワード設定を行います（[2-1 初回セットアップ](#2-1-初回セットアップ)を参照）。

#### ステップ 6: ステータスを ACTIVE に変更する

1. 「**受講者管理**」メニューで対象の受講者行を確認する
2. ステータスが `PENDING_ACTIVATION` の受講者行にある「**ステータス変更**」ボタンをクリックして `ACTIVE` に変更する
3. 受講者が動画受講を開始できるようになります

### 3-2. 受講者管理 (`/admin/users`)

サイドバーの「**受講者管理**」からアクセスします。受講者のテーブル一覧が表示されます。

#### テーブルの操作ボタン

| ボタン | 説明 |
|--------|------|
| ステータス変更 | 現在のステータスから次のステータスに 1 段階進める（確認ダイアログあり） |
| 入学申請 | 入学申請情報の登録ページ (`/admin/enrollment/new?userId={id}`) に遷移 |
| 詳細 | 受講者詳細ページ (`/students/{id}`) に遷移 |

右上の「**新規登録**」ボタンで受講者の新規作成ページ (`/admin/users/new`) に遷移します。

#### 受講者詳細 (`/students/{id}`)

受講者の基本情報（氏名・メール・コース・ステータス・登録日）を確認できます。  
受講者管理テーブルの「**詳細**」ボタンからアクセスします。

ステータスに応じて以下のアクションが表示されます：

| ステータス | 表示されるアクション |
|---|---|
| `PENDING_ACTIVATION` | 「招待メールを送信」ボタン（黄色の枠） |
| `EXAM_PASSED` | 「受講確認・成立判定へ」ボタン（青の枠） |
| `COMPLETED` / `CERTIFIED` / `DIPS_LINKED` | 「修了証明書画面へ」ボタン（緑の枠） |

---

### 3-3. 入学申請一覧 (`/admin/applications`)

サイドバーの「**入学申請**」からアクセスします。  
申請済みの全受講者の入学申請情報を一覧で確認できます。

#### 表示項目

| 列 | 説明 |
|----|------|
| 氏名 | 受講者の氏名 |
| メール | 受講者のメールアドレス |
| 申請日 | 入学申請の登録日（JST） |
| 受理状況 | 未受理 / 受理済（受理日時付き） |
| 身分証 | 身分証明書のアップロード状況（✓ / ✗） |
| 写真 | 顔写真のアップロード状況（✓ / ✗） |
| 経験証明 | 経験証明書のアップロード状況（✓ / ✗） |

> 現時点では一覧の閲覧のみです。受理状況の更新は今後の実装予定です。

---

### 3-4. コース管理 (`/courses`)

サイドバーの「**コース管理**」からアクセスします。コース一覧テーブル。操作：

- **新規コース作成:** 「新規コース作成」ボタンからモーダルで作成
- **編集:** 各行の「編集」ボタン
- **削除:** 各行の「削除」ボタン

---

### 3-5. 動画管理 (`/videos`)

サイドバーの「**動画管理**」からアクセスします。  
動画一覧テーブル（タイトル・科目・コース・再生時間・公開/非公開）。操作：

- **新規動画登録:** 「新規動画登録」ボタンからモーダルで登録
  - 動画ファイルは事前にサーバーの `/home/ubuntu/videos/` に配置が必要
- **編集:** 各行の「編集」ボタン
- **削除:** 各行の「削除」ボタン

---

### 3-6. 問題バンク (`/questions`)

サイドバーの「**問題バンク**」からアクセスします。問題一覧テーブル。操作：

- **新規作成:** 「新規作成」ボタンからモーダルで問題を作成
- **CSV インポート:** 「CSV インポート」ボタンで一括インポート
- **科目フィルタ:** 科目を選択して絞り込み
- **編集・削除:** 各行のボタン

---

### 3-7. 試験結果 (`/exam-results`)

サイドバーの「**試験結果**」からアクセスします。  
全受講者の試験履歴を確認できます。

表示項目：受験者名・メールアドレス・開始/終了日時・得点・合否・ステータス

---

### 3-8. 質疑応答管理 (`/admin/qa`)

サイドバーの「**質疑応答**」からアクセスします。

1. 「未回答のみ」フィルターで未回答の質問を確認する
2. 各質問の回答フォームに回答を入力して送信する
3. 回答は受講者の Q&A ページに反映されます

---

### 3-9. 受講確認・成立判定 (`/admin/students/{id}/review`)

試験合格済み（`EXAM_PASSED`）の受講者に対して行います。  
「**受講者管理**」→「**詳細**」ボタン→ 青い枠の「受講確認・成立判定へ」ボタンからアクセスします。

1. **科目別受講時間充足状況**を確認する（全科目が OK かどうか）
2. **不正フラグ**を確認する（タブ離脱・同時ログイン・速度違反の記録）
3. **判定フォーム**で「成立」または「不成立」を選択し、コメントを入力して送信する

| 判定結果 | ステータスの変化 |
|---|---|
| 成立 | → `COMPLETED`（修了） |
| 不成立 | 変化なし（判定履歴に記録のみ） |

---

### 3-10. 修了証明書の発行 (`/admin/students/{id}/certificate`)

修了済み（`COMPLETED`）の受講者に対して行います。  
「**受講者管理**」→「**詳細**」ボタン→ 緑の枠の「修了証明書画面へ」ボタンからアクセスします。

1. 「証明書を発行」ボタンをクリックする
   - 証明書番号が自動採番されます
2. 発行後、以下の操作が可能になります：
   - **PDF ダウンロード** — 様式1（修了証明書本体）
   - **交付台帳（様式5）のダウンロード** — 管理用の台帳 PDF

> **注意:** 証明書発行後は再発行できません。  
> PDF 生成やメール通知に失敗した場合はページ上部に警告が表示されます（証明書番号の発行自体は完了しています）。

## 4. 受講者ステータス一覧

```text
PENDING_REGISTRATION
        ↓ 管理者がステータス変更ボタンで変更
PENDING_ACTIVATION
        ↓ 管理者がステータス変更ボタンで変更（受講者のセットアップ完了後）
ACTIVE
        ↓ 受講者が試験に合格
EXAM_PASSED
        ↓ 管理者が「成立」判定
COMPLETED
        ↓ 証明書を発行
CERTIFIED
        ↓ 管理者がステータス変更ボタンで変更
DIPS_LINKED
```

| ステータス | 説明 | 遷移トリガー |
|------------|------|------------|
| `PENDING_REGISTRATION` | アカウント作成直後 | アカウント作成で自動設定 |
| `PENDING_ACTIVATION` | 招待メール送信可能な状態 | 管理者がステータス変更ボタンで変更 |
| `ACTIVE` | 受講中（動画視聴・試験が可能） | 管理者がステータス変更ボタンで変更 |
| `EXAM_PASSED` | 試験合格済み（成立判定待ち） | 受講者が試験に合格すると自動設定 |
| `COMPLETED` | 修了（成立判定済み・証明書発行可能） | 管理者が「成立」判定で設定 |
| `CERTIFIED` | 修了証明書発行済み | 証明書発行で自動設定 |
| `DIPS_LINKED` | DIPS 連携済み | 管理者がステータス変更ボタンで変更 |

## 5. よくある質問

### Q. ログインできない

- メールアドレスとパスワードが正しいか確認してください
- アカウントのステータスが `PENDING_ACTIVATION` の場合は、招待メールのリンクからセットアップを完了してください
- 管理者にステータスを確認してもらってください

### Q. 動画が視聴できない（ロック中と表示される）

前の動画を最後まで視聴すると次の動画のロックが解除されます。  
動画は順番に視聴する必要があります。

### Q. 試験を開始できない

全科目の受講時間を満たす必要があります。  
試験ページ (`/exams`) で不足科目と不足時間を確認してください。

### Q. 証明書 PDF がダウンロードできない

証明書ページで「PDF がまだ生成されていません」と表示されている場合は、  
事務局（管理者）にお問い合わせください。管理者画面から状況を確認します。

### Q. 管理者が証明書 PDF 生成失敗の警告が出る

証明書の発行自体は完了していますが、PDF の生成に失敗しています。  
事務局内で対応が必要です。証明書番号は発行済みのため、再発行はできません。

### Q. 招待メールを送信できない（ボタンが表示されない）

受講者のステータスが `PENDING_ACTIVATION` でない場合、招待ボタンは表示されません。  
「**受講者管理**」ページでステータスを確認し、「**ステータス変更**」ボタンで `PENDING_ACTIVATION` に変更してください。
