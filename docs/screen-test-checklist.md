手動での画面テスト (受け入れテスト) 用チェックリスト。
完了した項目は `[ ]` → `[x]` に変更し、NG項目は末尾の「NG記録」に記載する。

## 0. 事前準備

- [ ] seed 実行済みで、管理者アカウントでログインできる (seed 管理者の status が ACTIVE であること)
- [ ] テスト用の受講生アカウントが1つ以上ある (入学申請フローで作成するか seed で用意)
- [ ] テスト用の機体が1機以上登録済み (登録記号あり)
- [ ] テスト用の動画ファイルが1本以上配置済み

## 1. 認証 (ログイン・ログアウト)

- [ ] `/login` 管理者で正しいメール・パスワード → ログイン成功し管理者ホームへ遷移
- [ ] `/login` 受講生で正しいメール・パスワード → ログイン成功し受講生ホームへ遷移
- [ ] 誤ったパスワード → エラーメッセージ表示 (メール存在有無など内部情報を漏らさない文言)
- [ ] 存在しないメールアドレス → 同上のエラーメッセージ
- [ ] 無効化 (INACTIVE) 済みユーザー → ログイン不可
- [ ] 未ログイン状態で `/admin` へ直接アクセス → `/login` へリダイレクト
- [ ] 未ログイン状態で `/student` へ直接アクセス → `/login` へリダイレクト
- [ ] 未ログイン状態で `/flight/plans` へ直接アクセス → `/login` へリダイレクト
- [ ] ログアウト → セッション破棄され保護ページに戻れない
- [ ] ログイン試行を短時間に連続で失敗 → レート制限が発動する

## 2. 入学申請〜初回セットアップ (招待フロー)

- [ ] 入学申請を登録 → 管理者の `/admin/applications` に申請が表示される
- [ ] 管理者が申請を承認 → 招待メールが送信される (Resend)
- [ ] 招待メールのリンクから `/setup/password` が開ける
- [ ] パスワード設定: 弱いパスワード (短い等) → バリデーションエラー
- [ ] パスワード設定: 有効なパスワード → 次の規約同意へ進む
- [ ] `/setup/agreement` 規約に同意 → セットアップ完了、ログイン可能になる
- [ ] 同意せずに他ページへ直接アクセス → セットアップ画面へ誘導される
- [ ] 不正・期限切れの招待トークン → エラー表示 (詳細を漏らさない)
- [ ] `/admin/enrollment/new` 管理者による手動登録 → 同様に招待フローが開始される

## 3. 受講生画面

### 3-1. ホーム・コース

- [ ] `/student` 自分の進捗サマリが表示される
- [ ] `/courses` 自分にアクセス権のあるコースのみ表示される
- [ ] `/courses/[courseId]` 科目・動画一覧と進捗が表示される
- [ ] アクセス権のないコースのURL直打ち → 拒否される

### 3-2. 動画視聴

- [ ] `/courses/[courseId]/videos/[videoId]` 動画が再生できる
- [ ] 視聴後に進捗率が更新される
- [ ] 視聴ログが記録される (管理者側の受講生詳細で確認)
- [ ] 不正視聴パターン (大幅なスキップ等) → 不正フラグが記録される (`/admin/fraud-flags` で確認)

### 3-3. 修了確認試験

- [ ] `/exams` 受験可能な試験の一覧が表示される
- [ ] 受験条件 (進捗等) を満たさない試験 → 開始できない
- [ ] `/exams/[examId]` 出題 → 解答 → 提出が最後まで完了できる
- [ ] `/exams/[examId]/result` 合否・得点が表示される
- [ ] 提出済み試験の再提出 → 二重採点にならない

### 3-4. 質疑応答・修了証明書

- [ ] `/qa` 質問を投稿できる
- [ ] 管理者の回答が受講生側に表示される
- [ ] `/certificate` 修了者は修了証明書PDFをダウンロードできる
- [ ] 未修了者には証明書が表示されない

## 4. 管理者画面

### 4-1. ダッシュボード・ユーザー管理

- [ ] `/admin` 統計値 (受講生数等) が実データと一致する
- [ ] `/admin/users` 一覧表示・ロールフィルタが機能する
- [ ] `/admin/users/new` ユーザー作成 → 一覧に反映される
- [ ] ユーザー無効化 → 対象ユーザーがログイン不可になる
- [ ] メールアドレス重複で作成 → ユーザー向けエラーメッセージ

### 4-2. 受講生管理

- [ ] `/admin/students` 受講生一覧が表示される
- [ ] `/admin/students/[id]` 進捗・視聴ログ詳細が表示される
- [ ] `/admin/students/[id]/review` 受講確認 (成立判定) が実行できる
- [ ] `/admin/students/[id]/certificate` 修了証明書の交付ができる
- [ ] `/admin/judgments` 成立判定の一覧・記録が確認できる
- [ ] 修了証明書交付台帳 (様式5) PDFが出力できる

### 4-3. コンテンツ管理

- [ ] `/admin/courses` コースの作成・編集ができる
- [ ] `/admin/videos` 動画の登録・科目紐付けができる
- [ ] `/admin/questions` 問題バンクの登録・編集ができる
- [ ] `/admin/exam-results` 試験結果の一覧が確認できる
- [ ] `/admin/qa` 受講生の質問に回答できる
- [ ] `/admin/fraud-flags` 不正フラグの一覧・確認ができる

## 5. 飛行管理

### 5-1. 機体管理

- [ ] `/flight/aircraft` 自分の機体一覧が表示される
- [ ] `/flight/aircraft/new` 機体登録 (登録記号・重量等) ができる
- [ ] 必須項目未入力 → バリデーションエラー
- [ ] `/flight/aircraft/[id]` 詳細が表示される
- [ ] `/flight/aircraft/[id]/edit` 編集が反映される
- [ ] 機体の無効化 → 飛行計画作成時の機体選択肢に出なくなる

### 5-2. 飛行計画

- [ ] `/flight/plans` 一覧表示・ページネーション (Prev/Next) が機能する
- [ ] `/flight/plans/new` 計画作成ができる (タイトル・場所・日時・時間・目的)
- [ ] 過去日時を指定 → 入力できない (min属性)
- [ ] 他人の機体IDをAPI直叩きで指定 → 拒否される
- [ ] `/flight/plans/[id]` 詳細・リスク情報 (落下距離) が表示される
- [ ] 管理者: DRAFT → 承認 / 却下ができる
- [ ] 却下時に確認ダイアログが表示される
- [ ] 本人: APPROVED → 完了 (COMPLETED) にできる
- [ ] DRAFT の計画を編集 → 反映される
- [ ] APPROVED の計画を編集 → ステータスが DRAFT に戻り再承認が必要になる
- [ ] COMPLETED の計画 → 編集できない (エラーメッセージ表示)
- [ ] DIPS通報済みの計画 → 編集できない (エラーメッセージ表示)
- [ ] 一般ユーザーは自分の計画のみ、管理者は全件が見える

### 5-3. 飛行日誌

- [ ] `/flight/logs` 一覧が表示される
- [ ] `/flight/logs/new` 日誌作成 (飛行計画との紐付け) ができる
- [ ] `/flight/logs/[id]` 詳細が表示される
- [ ] `/admin/flight-logs` 管理者が全日誌を確認できる

## 6. DIPS連携 (本番サーバー検証環境限定)

> 前提: `.env` に DIPS_* 設定済み、`DIPS_ENABLED=true`、検証用 申請者ID (USR0630xx) を用意。

- [ ] `DIPS_ENABLED=false` のとき → DIPS通報ボタンが表示されない
- [ ] APPROVED かつ自分の計画の詳細に「DIPS通報」ボタンが表示される
- [ ] DRAFT / REJECTED / COMPLETED の計画には表示されない
- [ ] DIPS未認証で通報 → DIPSログイン画面へリダイレクトされる
- [ ] DIPSログイン完了 → `/redirect` 経由で計画一覧に戻る (`?dips=linked`)
- [ ] 通報ダイアログ: 飛行目的未選択 → エラー
- [ ] 通報ダイアログ: 緯度・経度の範囲外 (例: 経度200) → エラー
- [ ] 通報ダイアログ: 速度・高度の範囲外 (0や1000) → エラー
- [ ] 正しい入力で通報 → 成功し「DIPS通報済み (飛行計画ID: …)」表示に変わる
- [ ] 通報済みの計画 → 通報ボタンが表示されず、再通報できない
- [ ] 通報済みの計画 → 編集がブロックされる
- [ ] アクセストークン失効後 (5分放置) の再操作 → 自動リフレッシュされ操作が成功する
- [ ] DIPS側 (検証環境ポータル) で通報された飛行計画が確認できる

## 7. 権限境界

- [ ] 受講生アカウントで `/admin` 系URLへ直接アクセス → 拒否される
- [ ] 他ユーザーの飛行計画IDをURL直打ち → 404 (存在を漏らさない)
- [ ] 他ユーザーの機体IDをURL直打ち → 404
- [ ] 他受講生の試験結果・証明書へのアクセス → 拒否される
- [ ] ログアウト後にブラウザの「戻る」→ 保護ページの操作ができない

## 8. 表示・共通

- [ ] スマホ幅 (375px) で主要画面 (ログイン・一覧・詳細・フォーム) の表示が崩れない
- [ ] 日時がすべて日本時間 (JST) で表示される
- [ ] エラー時にユーザー向けメッセージが表示される (スタックトレース等が露出しない)
- [ ] 存在しないURL → 404ページが表示される
- [ ] 主要画面の初回表示が実用的な速度 (目安3秒以内)
