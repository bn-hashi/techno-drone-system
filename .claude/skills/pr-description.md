# /pr-description

現在のブランチと main の差分 (`git diff main...HEAD`) を確認し、
以下のフォーマットで Pull Request の説明文を**日本語**で出力してください。

## 出力フォーマット

```markdown
## 概要
<このPRが何を解決するのかを2〜3行で記載>

## 実装内容
- <変更点を箇条書き>

## テスト確認項目
- [ ] <レビュアーが確認すべきこと>
- [ ] <自動テストでカバーされた内容>

## 影響範囲
- <影響を受けるモジュール / API / 画面>

## AI レビュー対応状況
- [ ] `/verify` (ローカル) パス
- [ ] `/code-review` (ECC) パス
- [ ] CodeRabbit (GitHub) パス

## スクリーンショット (UI変更がある場合)
<該当なしの場合は「N/A」>

## 関連 Issue
Closes #<番号>
```

## ルール
- 推測で書かず、必ず diff から読み取れる事実のみ記載する
- 不明な項目は `(要記入)` とプレースホルダーを残す
- 破壊的変更がある場合は冒頭に `⚠️ Breaking Change` を明記する
